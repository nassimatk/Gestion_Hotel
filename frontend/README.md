# Frontend HotelHub (React + Vite)

```bash
npm install
npm run dev        # http://localhost:3000
```

- URL des services : `src/config/api.js` (toujours `localhost`, jamais les noms Docker).
- Un fichier par API dans `src/services/`.
- Pages client : `src/pages/client/` - pages admin : `src/pages/admin/`.
